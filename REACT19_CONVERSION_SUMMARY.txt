================================================================================
                            TROUBLESHOOTING
================================================================================

ISSUE: "Cannot find module '@/...'"
FIX: Check tsconfig.json path aliases match your file structure

ISSUE: "Build fails with peer dependency errors"
FIX: npm install --legacy-peer-deps

ISSUE: "Dev server won't start"
FIX: Kill process on port 5173 or use different port

ISSUE: "Token not being sent with API requests"
FIX: Verify you're using apiClient from @services/base-api

ISSUE: "401 logout not working"
FIX: Check that useAuthStore.logout() is called on 401 response

ISSUE: "Imports not working"
FIX: Clear node_modules and reinstall: rm -rf node_modules && npm install
